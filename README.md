# Crime Data Analysis Dashboard

## Project Overview

This Power BI dashboard analyzes crime data to identify crime patterns, regional trends, victim demographics, and category-wise crime distribution. The dashboard helps in understanding crime insights using interactive visualizations and KPI tracking.

---

## Features

- Crime trend analysis by region and time
- Category-wise crime distribution
- Victim demographic analysis
- Interactive slicers and filters
- KPI cards and dynamic visualizations
- Data cleaning and transformation
- DAX calculations for analytical insights

---

## Tools & Technologies Used

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Cleaning
- Data Visualization

---

## Dashboard Insights

- Identified regions with high crime rates
- Analyzed crime distribution across categories
- Compared crime trends over time
- Generated actionable insights using interactive reports
